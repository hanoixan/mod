# data: width_table

A generated C++ initializer list of Unicode code-point ranges that have a non-default display width, character class or grapheme-break property. The grapheme-break columns serve cursor movement and deletion by extended grapheme cluster ([next_grapheme_boundary](./utf8.hpp.skel.md#function-next_grapheme_boundary)). It is checked into the repository so that builds need no network access and no Python.

- **Source:** generated — by [gen_width_table.py](../../tools/gen_width_table.py.skel.md) from Unicode Character Database files.
- **Required:** always.
- **Failure modes:** the file is hand-edited and drifts from the generator, so CI reruns the generator and diffs the result. Ranges that are unsorted or overlap break the binary search, so the generator asserts sorted, disjoint ranges.
- **Depends on:** [gen_width_table.py](../../tools/gen_width_table.py.skel.md)
- **Unknowns:** none
- **Referred by:** [utf8 (implementation)](./utf8.cpp.skel.md)
- **Referred by:** [display_width](./utf8.hpp.skel.md#function-display_width)

## Schema

```cpp
// Generated by tools/gen_width_table.py — Unicode 16.0.0. DO NOT EDIT.
// One entry per maximal run of code points with identical (width, class, gcb, flags).
// Sorted by `first`, disjoint, and only non-default entries
// (default = width 1, class word, gcb Other, no flags).
// width: 0 | 1 | 2 (controls render as ^X); cls: space|word|punct|control
// gcb: Grapheme_Cluster_Break = CR|LF|Control|Extend|ZWJ|Regional_Indicator|Prepend|
//      SpacingMark|L|V|T|LV|LVT|Other
// flags: GF_EXTPICT (Extended_Pictographic), GF_INCB_LINKER / GF_INCB_CONSONANT /
//      GF_INCB_EXTEND (Indic_Conjunct_Break)
{ 0x0000,  0x0009,  0, CC_CONTROL, GB_CONTROL, 0 },
{ 0x000A,  0x000A,  0, CC_CONTROL, GB_LF,      0 },
{ 0x000D,  0x000D,  0, CC_CONTROL, GB_CR,      0 },
{ 0x0020,  0x0020,  1, CC_SPACE,   GB_OTHER,   0 },
{ 0x0300,  0x034E,  0, CC_WORD,    GB_EXTEND,  GF_INCB_EXTEND },   // combining marks: width 0
{ 0x1100,  0x115F,  2, CC_WORD,    GB_L,       0 },                // Hangul leading jamo: wide
{ 0x1F1E6, 0x1F1FF, 1, CC_WORD,    GB_REGIONAL_INDICATOR, 0 },
// ... about 3–5k lines
```

## Generation

Pipeline:

1. Inputs: `EastAsianWidth.txt`, `extracted/DerivedGeneralCategory.txt`, `emoji/emoji-data.txt`, `auxiliary/GraphemeBreakProperty.txt` and `DerivedCoreProperties.txt` (for `InCB`) for the pinned Unicode version, downloaded from `https://www.unicode.org/Public/<ver>/ucd/` (paths relative to that directory) into a temporary directory. The files are not committed. Each file's header must name the version.
2. [gen_width_table.py](../../tools/gen_width_table.py.skel.md) assigns widths: Mn, Me, Cf, Cc and Hangul medial and final jamo (`Grapheme_Cluster_Break` V and T) → 0, taking precedence; then W and F → 2; `Extended_Pictographic` with `Emoji_Presentation` → 2. It assigns classes: Z* → space; P* and S* → punct; Cc → control. It copies `Grapheme_Cluster_Break` as-is, sets `GF_EXTPICT` from `Extended_Pictographic` (independently of `Emoji_Presentation`), and sets the `InCB` flags. It then merges adjacent equal entries.
3. The output is written here. The tool asserts invariants and prints the number of ranges. With `--test-out`, it also writes the cases from `auxiliary/GraphemeBreakTest.txt` as a C++ table for [editor_test](../../tests/editor_test.cpp.skel.md); see below.

It runs manually when the pinned Unicode version is bumped. CI runs it with `--check`, which exits non-zero on any difference.

```bash
python3 tools/gen_width_table.py --unicode 16.0.0 --out src/text/width_table.inc
python3 tools/gen_width_table.py --unicode 16.0.0 --check src/text/width_table.inc --test-out tests/grapheme_break_cases.inc
python3 tools/gen_width_table.py --unicode 16.0.0 --out src/text/width_table.inc --test-out tests/grapheme_break_cases.inc
```
