# module: settings_test

The schema table (unique keys, defaults within range, a label and help text for every row; `tab_width` is an integer 1 to 16 defaulting to 4, the three View starting values that default to true and `word_wrap`, which defaults to false, are booleans; `setting_value_text`). A missing directory or file gives every default with no warning; an unavailable configuration directory is never read or written; a valid file gives its values and absent keys keep their defaults; a file written by an older `mod` (`{"tab_width":2}`) still loads; a file that cannot be used (invalid JSON, not an object, invalid bytes) gives the defaults with a "settings.json ignored" warning and is left untouched; a bad value (0, 17, a string, a fraction, a boolean for a number, a number for a boolean) gives that setting's default with a warning while the other settings still load; `set` creates the directory and the file and a second `Settings` loads it, with a boolean stored as a JSON boolean; `set` refuses an unknown key and a value out of range and writes nothing; unknown keys survive a write, also inside `modified`; an unchanged value writes nothing and is not stamped; each change is stamped with its time (an injected clock) in the file and `recent` lists the newest first, honors its cap, and comes back in the same order from the file; hand-written times without milliseconds are read and malformed ones ignored, and a `modified` that is not an object is replaced on the next `set`; a structured member (`keymap`) is written with `set_raw`, read back with `raw`, written only when it changes, kept across scalar writes, never stamped or listed as recent, refused by `set`, and removed with `nullopt`; an unwritable directory returns `permission` and the value still applies; a configuration path that is a file fails with `io`. A choice setting (`terminal_mode`): its names, written and read as a name, a bad name or a number warned and defaulted, and its default in the reference file as a quoted name. `markdown_formatting` is no longer a setting: absent from the schema and the reference file, and an old member is kept untouched when the file is rewritten. `darkness` is a choice of night, normal and paper, normal by default. `cursor_style` is a choice of six shapes, `bar` by default. `tab_inserts` is spaces or tab, spaces by default; `word_wrap` is on by default. The view settings are labeled "... on open". read_only_copy is a choice of markdown and visible text, markdown by default. An override is never written, a later set of its key replaces it and is saved, and setting another key leaves it out of the file. A symlinked settings.json stays a symlink and keeps its permissions; two Settings on one folder changing different settings keep both changes. The choice settings read back as their own types.
