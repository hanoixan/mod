# data: grapheme_break_cases

A generated C++ initializer list of the UAX #29 grapheme-break conformance cases, so that [editor_test](./editor_test.cpp.skel.md) can check [next_grapheme_boundary](../src/text/utf8.hpp.skel.md#function-next_grapheme_boundary) and [prev_grapheme_boundary](../src/text/utf8.hpp.skel.md#function-prev_grapheme_boundary) against Unicode's own test data. It is checked into the repository for the same reason as [width_table.inc](../src/text/width_table.inc.skel.md): builds and tests need no network and no Python.

- **Source:** generated — by [gen_width_table.py](../tools/gen_width_table.py.skel.md) from `auxiliary/GraphemeBreakTest.txt` for the same pinned Unicode version as the width table.
- **Required:** conditional — when `MOD_BUILD_TESTS` is ON.
- **Failure modes:** the file is generated for a different Unicode version than `width_table.inc`, so cases fail for reasons unrelated to the code. Both files are written by one run of the generator and carry the version in their header comment, and the test asserts that the two versions match.
- **Depends on:** [gen_width_table.py](../tools/gen_width_table.py.skel.md)
- **Referred by:** [editor_test](./editor_test.cpp.skel.md)
- **Unknowns:** none

## Schema

```cpp
// Generated by tools/gen_width_table.py from GraphemeBreakTest.txt — Unicode 16.0.0. DO NOT EDIT.
// One entry per test line: the code points, encoded as UTF-8, and the byte
// offsets of every cluster boundary, including 0 and the total length.
// The string may contain NUL bytes; its length is the last offset.
{ "\x0D\x0A",                 { 0, 2 } },        // ÷ 000D × 000A ÷
{ "\x61\xCC\x81",             { 0, 3 } },        // ÷ 0061 × 0301 ÷
{ "\xF0\x9F\x87\xA6\xF0\x9F\x87\xA6\xF0\x9F\x87\xA6", { 0, 8, 12 } },  // RI RI | RI
// ... about 1–2k lines
```

## Generation

Pipeline:

1. Input: `auxiliary/GraphemeBreakTest.txt` for the pinned Unicode version, fetched alongside the files listed in [width_table.inc](../src/text/width_table.inc.skel.md#generation), or read from `--ucd-dir`.
2. [gen_width_table.py](../tools/gen_width_table.py.skel.md) parses each line's `÷` (break) and `×` (no break) markers, encodes the code points as UTF-8, and converts break positions to byte offsets.
3. The output is written here, in the same run that writes the width table. CI runs the generator with `--check` on both files.

```bash
python3 tools/gen_width_table.py --unicode 16.0.0 --out src/text/width_table.inc --test-out tests/grapheme_break_cases.inc
```
